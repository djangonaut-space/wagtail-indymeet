Help: actions & columns on this page
Bulk actions (the "Action:" dropdown below the list)
  • Copy selected event and open as new [runs immediately] — requires exactly one selected event; opens the add form pre-filled with that event's data so you can review, edit, and save it as a new event. Nothing is saved until you submit that form.
  • Send calendar invites to event members [shows a confirmation page] — shows the computed recipients and current session/Public/Published settings for the selected events; invites are only queued once you confirm. You can use this multiple times. Resending invites will only resend invites to those who haven't gotten them. Recipients depend on the audience, plus the event's extra emails:
    • Session — the linked session's accepted members.
    • Community — everyone who has ever been an accepted session member.
    • Public — only the extra emails.
  • Resync to Zoom and Discord [runs immediately] — force-resyncs the selected events, updating the existing Zoom meeting/Discord event even if already synced. If calendar invites were already sent, recipients' calendars won't reflect the updated details.
  • Send time(s) changed calendar updates [shows a confirmation page] — emails an updated invite to everyone already sent one. People whose invite hasn't been sent aren't emailed.
Only "Send calendar invites to event members" and "Send time(s) changed calendar updates" show a confirmation page first — the other actions run right away when you choose them from the dropdown and click "Go".
List columns
  • Calendar invites sent at — when calendar invites were emailed to members; blank means none have been sent yet.
  • Zoom synced — whether a Zoom meeting has been created/updated for this event.
  • Discord synced — whether a Discord scheduled event has been created/updated for this event.
