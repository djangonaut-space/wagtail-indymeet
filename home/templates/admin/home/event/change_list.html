Help: actions & columns on this page
Bulk actions (the "Action:" dropdown below the list)
  • Copy selected event and open as new [runs immediately] — requires exactly one selected event; opens the add form pre-filled with that event's data so you can review, edit, and save it as a new event. Nothing is saved until you submit that form.
  • Send calendar invites to event members [shows a confirmation page] — shows the computed recipients and current session/Public/Published settings for the selected events; invites are only queued once you confirm. Only sends once per event — skipped for events that already have invites sent. Recipients depend on the event:
    • Session event — all members of that session who have an email address.
    • Public event (no session) — all users opted in to event updates.
    • Private event (no session) — no extra recipients; still sends to the event's configured extra emails (e.g. sessions@djangonaut.space).
  • Resync to Zoom and Discord [runs immediately] — force-resyncs the selected events, updating the existing Zoom meeting/Discord event even if already synced. If calendar invites were already sent, recipients' calendars won't reflect the updated details.
Only "Send calendar invites to event members" shows a confirmation page first — the other actions run right away when you choose them from the dropdown and click "Go".
List columns
  • Calendar invites sent at — when calendar invites were emailed to members; blank means none have been sent yet.
  • Zoom synced — whether a Zoom meeting has been created/updated for this event.
  • Discord synced — whether a Discord scheduled event has been created/updated for this event.
